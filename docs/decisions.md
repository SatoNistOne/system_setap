# Golden setup — принятые решения

Единственный источник правды по решениям (ревизия 2026-10-11/12, все пункты
подтверждены заново). Только «что» и коротко «почему» — без кода и истории
правок. Код — в репозитории; открытые вопросы и следующие шаги — `todo.md`;
проверки на живой системе — `tests.md`.

Обозначения: **[ноут]** / **[ПК]** — только на этом типе машины;
**[личное]** — только в личном слое (мои машины, не у друзей);
**⚠️** — проверить вживую (есть в `tests.md`).

---

## 1. Цель и устройство проекта

- Воспроизводимая система Arch + Niri + Noctalia для моих двух машин
  (ноут Colorfire: Ryzen 9 7845HX + RTX 4070 Laptop; ПК) и пары друзей.
- **Два слоя.** Общий — публичный репозиторий chezmoi (код, конфиги,
  базовые пакеты); изменения доходят до друзей только по их `golden-update`.
  Личный — ответы на вопросы при установке и мои пакеты, хранятся локально
  (`~/.config/chezmoi/chezmoi.toml`), в репозиторий не попадают.
- **Установка в две фазы.** (1) `install.sh` с live-ISO задаёт все вопросы,
  archinstall работает под капотом без участия пользователя. (2) После первой
  загрузки — одна команда `chezmoi init --apply <URL>`.
- **Вопросы при установке:** логин, отображаемое имя (необязательно),
  пароль пользователя, пароль шифрования диска, имя машины, часовой пояс,
  optional-пакеты, роли дополнительных дисков, числа ryzenadj (если нужно).
- **Раскладка репозитория:** конфиги в `$HOME` — `dot_*`-файлы chezmoi;
  системные файлы — `system/…` + `run_onchange`-скрипт с хэшем (поправил
  файл → при следующем apply переложится); генерируемое по железу пишет
  скрипт. Списки пакетов — файлами в репозитории.
- **Детект железа** — в `~/.local/state/chezmoi-hw-facts.env`: шасси, вендор
  CPU, GPU по PCI vendor ID, гибрид, LUKS, системный диск.
- **Миграции** как в Omarchy: `migrations/<время>.sh`, каждая выполняется
  один раз на машине при `golden-update` — для изменений вне конфигов.
- Язык установщика, меню и сообщений — **английский**.
- Качество: shellcheck в GitHub Actions на каждый коммит; тестовая
  установка в QEMU до реальной. Режим `--dry-run` не делаем.

|---|---|---|
| Дистрибутив | Arch Linux | Минимализм, AUR, обучение |
| Ядро | `linux-cachyos` + запасное `linux-lts` из Arch | BORE и готовые модули Nvidia; запасное — из другого источника |
| Nvidia под LTS | `nvidia-open-lts` ⚠️ имя пакета | |
| Загрузчик | Limine + limine-snapper-sync | Загрузка в снапшот из меню |
| Композитор | Niri | Скроллируемый тайлинг, Wayland |
| Оболочка | Noctalia v5 | Бар, уведомления, центр управления, lock, idle; обновлять осознанно (changelog, откат снапшотом) |
| Свой шелл | Позже, отдельным проектом, на Quickshell | |

| Связка ключей | Пустая связка по умолчанию, как в Omarchy; PAM-правок для keyring нет | Защита — LUKS; при автологине пароля входа нет |
| SSH-агент | gcr-ssh-agent | Пароль ключа хранится в связке |

## 3. Безопасность

- **LUKS на всех машинах** (с подтверждением при установке).
- **Файрвол nftables:** всё входящее закрыто, `forward` закрыт; разрешён
  исходящий трафик контейнеров Docker. Syncthing, mDNS, SSH, RustDesk —
  входящих портов нет.
- **`port-open <порт>` / `port-close`:** временно открыть порт только для
  локальной сети, сам закрывается через час. Один механизм для программ на
  машине и для проброшенных портов Docker. ⚠️ Docker + forward в QEMU.
- **DNS:** systemd-resolved, DoT на Quad9 (запасной Cloudflare), строгий
  режим; исключения для отдельных сетей (оппортунистический) через
  NetworkManager ⚠️. DNS в Firefox — системный (DoH в браузере выключен).
- **`golden-dns`** (на основе omarchy-dns, MIT) в меню: Quad9 строгий /
  оппортунистический / DNS провайдера / свой / «для этой сети».
- **USBGuard + notifier** на всех машинах; политика генерируется до
  включения службы.
- **faillock:** 10 попыток, блок на 2 минуты (как в Omarchy).
- **sysctl:** только `kernel.yama.ptrace_scope=1`, `kernel.kptr_restrict=1`.
- **Чёрный список модулей:** dccp, sctp, rds, tipc, cramfs, freevxfs,
  jffs2, hfs, hfsplus.
- **Не берём:** AppArmor, hardened_malloc.
- **Secure Boot:** не в установщике; отдельная команда `golden-secureboot`
  после обкатки (sbctl, ключи Microsoft оставить, подпись Limine), потом по
  желанию — разблокировка диска через TPM (для удалённой перезагрузки ПК).
- **Удалённый доступ:** RustDesk через свой сервер (рабочий стол) ⚠️
  доступ без подтверждения на Niri; SSH через сервер (обратный туннель,
  `ssh -J`). Sunshine и Remote Play — не берём.

## 4. Диски, снапшоты, сон

- **btrfs, сабвольюмы:** `@`, `@home`, `@log`, `@pkg`, `@.snapshots`,
  `@docker` (`/var/lib/docker`, вне снапшотов); zstd, noatime,
  discard=async. `/tmp` — tmpfs по умолчанию.
- **Снапшоты системы** (snap-pac на каждую операцию pacman): 10 обычных +
  10 «важных» (ядро, Nvidia, Mesa, systemd, glibc, Limine, mkinitcpio);
  `FREE_LIMIT=0.2`; в меню Limine — 10 последних.
- **Снапшоты `/home`:** раз в день, хранить 7. Вложенные тома вне
  снапшотов: `~/.local/share/Steam`, `~/.cache`.
- **Откат:** загрузиться в снапшот из Limine → `limine-snapper-restore` ⚠️.
  `snapper rollback` не используем.
- **`golden-disks`** (при установке и из меню): все диски, кроме системного,
  zram и съёмных. Роли: оставить / хранилище (LUKS с ключ-файлом на
  системном диске + резервный пароль, btrfs, тома `data` со снапшотами и
  `media` без, `/mnt/<имя>`, `nofail`, TRIM только для SSD) / бэкап (btrbk:
  `/home` и `data` раз в день). Диски с данными — только с подтверждением.
- **[ПК]** второй диск SSD — хранилище; будущий HDD — роль «бэкап».
- `~/Projects` — на системном диске на всех машинах.
- **scrub** btrfs раз в месяц для всех дисков. Квоты btrfs не используем.
- **Своп:** zram (min(RAM/2, 4 ГБ), zstd). **[ноут]** + своп-файл = RAM для
  гибернации; **[ПК]** только zram.
- **Сон [ноут]:** крышка → `suspend-then-hibernate`; критический заряд →
  гибернация. ⚠️ Nvidia + гибернация.
- **Бездействие:** скринсейвер 2,5 мин, блокировка 5 мин, экран гаснет
  10 мин; сон — ноут от батареи 15 мин, от сети 30 мин, ПК — никогда.
  Видео, игры, звонки запрещают; кнопка «Не засыпать» в баре.

## 5. Железо и питание

- **power-profiles-daemon** (TLP не используем).
- **[ноут] Порог заряда 80%** (все `BAT*`), пункт меню «зарядить до 100%
  один раз».
- **[ноут] ryzenadj** — обход прошивки (544 МГц на зарядке под нагрузкой).
  Таблица проверенных CPU в репозитории (7845HX: 54/65/54 Вт, tctl 95):
  такой же CPU — без вопросов; другой Ryzen-ноут — вопрос про числа; пусто —
  не ставить. На батарее — заводские значения, снятые `ryzenadj -i` ⚠️
  (до замера 15/25/15). Применяется при загрузке, после сна и при
  подключении/отключении зарядки.
- **[ноут] Nvidia:** гибрид + RTD3 (envycontrol), nvidia-powerd. Видео
  декодирует встроенная графика. Индикатор «Nvidia активна» в баре; кнопка
  «только встроенная» — только если проверка покажет, что Nvidia не
  засыпает ⚠️.
- **Обновления Nvidia** — вместе со всем, страховка — «важные» снапшоты и
  новости перед обновлением.
- **Мониторы:** все экраны работают одновременно; настройки привязаны к
  конкретным мониторам в `config.kdl`; повтор экрана — пункт меню (wl-mirror)
  ⚠️. Kanshi не используем.
- **Сеть и Bluetooth** — панели Noctalia; запасные `nmtui` и
  `bluetoothctl` пунктами меню.
- **Печать** (изредка, чужие принтеры): CUPS по сокету, без драйверов (IPP
  Everywhere), system-config-printer; «Найти принтеры» — временно открывает
  mDNS на час; иначе — по IP.
- **Звук:** PipeWire 48 кГц, quantum 1024 (фикс щелчков); EasyEffects —
  шумодав на микрофоне включён, эквалайзер есть, выключен.
- fwupd — только показ обновлений прошивок, ставить вручную.

## 6. Оболочка, меню, вид

- **Бар Noctalia** (сверху): логотип → меню, рабочие столы | не засыпать,
  часы, раскладка, погода, обновления | трей, лимиты Claude, Nvidia
  [ноут], уведомления, Bluetooth, сеть, яркость (скрыта на ПК), батарея
  [ноут], центр управления.
- **Одно меню** на `Super+Space` и по клику на логотип, в стиле Omarchy:
  дерево из `menu.jsonc` (подменю, условия, ✓), рисует fuzzel; позже тот же
  файл читает свой шелл. Внутри: приложения, конфиги (через
  `chezmoi edit --apply`), система (блокировка, сон, гибернация,
  перезагрузка, выключение), настройки (DNS, порты, тема, часовой пояс,
  повтор экрана, батарея 100%, печать, Docker без sudo, установить/удалить
  пакет, nmtui/bluetoothctl, скринсейвер). Лаунчер Noctalia не используем.
- **Виджет лимитов Claude [личное]:** основной источник — строка статуса
  Claude Code (`rate_limits` → `~/.cache/claude-usage.json`, 0 токенов);
  запасной — неофициальный адрес, редко и только при устаревших данных;
  подпись «на момент …»; подсветка выше 80%. Плюс статистика токенов по
  дням и моделям из локальных логов `~/.claude/projects` (как в Omarchy,
  можно взять их код, MIT).
- **Темы как в Omarchy:** тема = палитра `colors.toml` + обои + иконки;
  шаблоны для kitty, fuzzel, Noctalia, btop, VS Code, qt6ct, фона Plymouth,
  Satty; переключение одной командой и пунктом меню с превью. GTK —
  Adwaita тёмная/светлая + иконки. Для старта 3–4 палитры из Omarchy (MIT), остальные добавляются
  копированием папки; по умолчанию **Vantablack**.
- **Экран загрузки и скринсейвер в стиле Omarchy:** тема Plymouth Omarchy
  (MIT) с логотипом-баннером; скринсейвер — `ttfx` анимирует баннер на весь
  экран. Баннер — из отображаемого имени, введённого при установке (поле
  GECOS, иначе логин; нелатинское имя → логин). ⚠️ шрифт баннера.
- **Обои:** живые (linux-wallpaperengine) на всех машинах; **[ноут]** от
  батареи живые обои останавливаются и вместо них ставится статичный
  первый кадр (превью из Wallpaper Engine или первый кадр видео через
  ffmpeg), нагрузка ≈ 0; от сети — анимация запускается заново ⚠️; пауза в полноэкранных
  окнах; звук обоев выключен; на каждый монитор свои.
- **Шрифты:** Noto (+cjk, emoji, extra) для интерфейса, JetBrainsMono Nerd
  Font для терминала и кода.
- **Niri:** раскладки us+ru, переключение `Alt+Shift`; тачпад — касание,
  натуральная прокрутка, выключение при наборе; небольшие отступы, тонкая
  рамка активного окна, без скруглений. Сочетания клавиш — составить с нуля
  (см. `todo.md`). Уведомления Steam — сбоку справа (готовое правило окна).
- **Скриншоты:** встроенные в Niri (`Print` — область/окно/экран в буфер и
  `~/Pictures/Screenshots`); `Shift+Print` — сразу в Satty для пометок.
- **Буфер обмена:** cliphist (переживает перезагрузку), 750 записей,
  старше 7 дней удаляются; `Super+V` и пункт меню ⚠️ пароли не сохраняются.

## 10. Синхронизация и сервер

- **Syncthing** синхронизирует только `~/Projects/syncthing` через
  постоянный узел на моём сервере.
- **pkgdiff [личное]:** каждая машина хранит свой список пакетов (и
  Flatpak) в папке Syncthing; команда `pkgdiff` и пункт меню показывают
  «есть на ПК, нет на ноуте» и наоборот (без железных пакетов) → отмечаешь
  нужное → ставится. Без уведомлений и слежения; удаления не
  синхронизируются.
- **Сервер** (после установки, рядом с VPN): RustDesk (hbbs/hbbr), узел
  Syncthing, точка входа SSH-туннелей. Бэкап на сервер не делаем.
- **Бэкапы:** снапшоты + копия в Syncthing; бэкап вне диска — см.
  `todo.md` (решается); с HDD — роль «бэкап» в `golden-disks` (btrbk).
  Диск сервера (40 ГБ на всё: система, VPN, RustDesk, Syncthing) не
  забивать.
- **Заголовок LUKS:** после установки копия на аварийную флешку (скрипт
  просит вставить флешку); пункт меню «Сохранить заголовок LUKS» —
  повторять после смены пароля, старые копии удалять.
- **Аварийная флешка** (Ventoy уже есть): Arch ISO + копия заголовка LUKS +
  `RECOVERY.md` из репозитория (снапшот, `linux-lts`, chroot и переустановка
  Limine, восстановление заголовка).

## 11. Обновления и обслуживание

- **`golden-update`** (команда и пункт меню): новости Arch и CachyOS (стоп
  при ручном вмешательстве) → `paru -Syu` (снапшоты сами, диффы AUR) →
  Flatpak → rustup / mise / uv tool / cargo-binstall → миграции →
  `chezmoi update` с вопросом → итог: нужна ли перезагрузка, `.pacnew`
  (pacdiff), обновления прошивок.
- **Автоматически:** paccache (2 версии), место > 85% и SMART — каждый
  день, scrub — раз в месяц, журнал не больше 500 МБ, зеркала — раз в
