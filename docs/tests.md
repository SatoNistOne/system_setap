# Проверки при первой установке

Всё, что в плане помечено «проверить вживую». Отмечай `[x]` по ходу.
Где написано «QEMU» — можно проверить ещё до реальной установки, в виртуалке.

## Как тестировать мониторы без лишних мониторов

- **QEMU с двумя-тремя виртуальными экранами:** `-device virtio-vga-gl,max_outputs=2` (или `max_outputs=3`) — каждый экран открывается отдельным окном. Подходит для проверки повтора экрана, расстановки мониторов и подключения/отключения (выход можно «выдернуть» из монитора QEMU).
- **Телевизор по HDMI** — самый простой реальный второй экран для ноута.
- **Монитор ПК для ноута** — ты и так иногда подключаешь ноут к одному из них.
- Привязку настроек к конкретным мониторам ПК (по модели и серийнику) проверить можно только на самом ПК.
