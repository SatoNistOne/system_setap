# Шпаргалка по системе

Справочник частых команд с упражнениями. Открыть в терминале: `golden-guide`.
Создать песочницу для упражнений: `golden-practice` (папка `~/golden-practice`,
её можно спокойно ломать и пересоздавать).

Шелл — fish, все примеры написаны под него.

## 0. Где искать справку

| Команда | Что даёт |
|---|---|
| `tldr tar` | 5–10 самых частых примеров для команды (первый раз: `tldr --update`) |
| `rg --help` | краткая справка по флагам |
| `man rg` | полная документация (`/слово` — поиск, `n` — следующее, `q` — выход) |
| `type ll` | что на самом деле запускается под этим именем (функция, алиас, программа) |

## 1. fish — сам шелл

| Действие | Как |
|---|---|
| Принять серую подсказку из истории | `→` или `Ctrl+F`; одно слово — `Alt+→` |
| Дополнение | `Tab` (повторный `Tab` — меню, листается стрелками) |
| Поиск по истории | `Ctrl+R` (atuin) |
| Вставить путь к файлу через fzf | `Ctrl+T` |
| Перейти в папку через fzf | `Alt+C` |
| Назад/вперёд по посещённым папкам | `Alt+←` / `Alt+→` (при пустой строке) |
| Открыть команду в редакторе | `Alt+E` |
| Код выхода прошлой команды | `echo $status` |

Отличия от bash, о которые спотыкаются чаще всего:
```fish
set name значение            # вместо name=значение
set -gx EDITOR nano          # вместо export EDITOR=nano
echo (date)                  # подстановка — круглые скобки, не $(...)
make; and echo ok            # вместо &&  (новые версии fish понимают и &&)
for f in *.txt
    echo $f
end                          # циклы и if закрываются словом end
```

## 2. Навигация и файлы

| Команда | Что делает |
|---|---|
| `cd проект` | zoxide: прыжок в часто посещаемую папку по части имени |
| `cdi` | то же, но с выбором из списка |
| `cd -` | в предыдущую папку |
| `ls` / `ll` / `la` / `lt` | eza: список / подробно с git-статусом / со скрытыми / деревом |
| `eza -l --sort=size` | по размеру |
| `yazi` | файловый менеджер в терминале |
| `trash файл` | в корзину вместо `rm` (восстановить: `trash-restore`) |

Клавиши yazi: `hjkl` или стрелки — ходить, `Enter` — открыть, `Space` —
выделить, `y` — копировать, `x` — вырезать, `p` — вставить, `d` — в корзину,
`a` — создать (имя с `/` на конце — папка), `r` — переименовать, `.` —
скрытые файлы, `z` — прыжок через zoxide, `q` — выход.

**Упражнения** (после `golden-practice`):
1. `cd ~/golden-practice/project`, потом `cd ~`, потом просто `cd proj` — zoxide
   уже запомнил путь.
2. `lt` внутри `project` — дерево. Сравни с `la`: видно скрытую `.hidden/`.
3. Открой `yazi`, создай папку `tmp/`, скопируй туда `notes/todo.md`, удали
   папку в корзину.

## 3. Просмотр содержимого

| Команда | Что делает |
|---|---|
| `cat файл` | bat: подсветка и номера строк (в пайпах ведёт себя как обычный cat) |
| `bat -p файл` | без номеров и рамки |
| `bat -r 10:20 файл` | только строки 10–20 |
| `bat -A файл` | показать невидимые символы (табы, переводы строк) |
| `glow README.md` | красиво отрисованный markdown |
| `tail -f logs/app.log` | следить за файлом в реальном времени (`Ctrl+C` — выход) |
| `jq . config.json` | отформатировать JSON |
| `jq '.servers[].name' config.json` | вытащить поле из каждого элемента массива |

**Упражнения:**
1. `cat src/main.rs`, затем `bat -p src/main.rs` — найди разницу.
2. `jq '.servers[] | select(.port > 8000) | .name' config.json` — имена серверов с портом больше 8000.

## 4. Поиск файлов: fd и find

| Задача | fd | find |
|---|---|---|
| По части имени | `fd main` | `find . -iname '*main*'` |
| По расширению | `fd -e rs` | `find . -name '*.rs'` |
| Только папки | `fd -t d` | `find . -type d` |
| Включая скрытые | `fd -H secret` | по умолчанию |
| Включая игнорируемые git | `fd -I junk` | по умолчанию |
| Глубина | `fd -d 2 …` | `find . -maxdepth 2 …` |
| Изменённые за сутки | `fd --changed-within 1d` | `find . -mtime -1` |
| Больше 1 МБ | `fd -S +1m` | `find . -size +1M` |
| Выполнить команду для каждого | `fd -e md -x wc -l` | `find . -name '*.md' -exec wc -l '{}' \;` |
| По правам (SUID) | — | `find / -perm -4000 2>/dev/null` |

Правило: руками в проекте — `fd`; в скриптах и по системным папкам — `find`
(fd по умолчанию пропускает скрытое и то, что в `.gitignore`, — для системы
это неправильно).

**Упражнения** (в `~/golden-practice/project`):
1. `fd junk` ничего не найдёт, а `find . -name '*junk*'` — найдёт. Почему?
   (Подсказка: `bat .gitignore`.) Теперь `fd -I junk`.
2. `fd secret` — пусто; `fd -H secret` — нашёл.
3. Посчитай строки во всех `.rs`: `fd -e rs -x wc -l`.

## 5. Поиск текста: rg и grep

| Задача | rg | grep |
|---|---|---|
| Рекурсивно по папке | `rg TODO` | `grep -rn TODO .` |
| Без учёта регистра | `rg -i todo` | `grep -rni todo .` |
| Умный регистр (с заглавными — точно) | `rg -S Todo` | — |
| Целое слово | `rg -w error` | `grep -rnw error .` |
| Только имена файлов | `rg -l TODO` | `grep -rl TODO .` |
| Посчитать совпадения | `rg -c ERROR` | `grep -rc ERROR .` |
| Только Rust-файлы | `rg -t rust TODO` | `grep -rn --include='*.rs' TODO .` |
| Исключить папку | `rg TODO -g '!logs'` | `grep -rn --exclude-dir=logs TODO .` |
| Контекст ±2 строки | `rg -C 2 ERROR` | `grep -rn -C 2 ERROR .` |
| Строка как есть, без регулярки | `rg -F 'a.b(c)'` | `grep -rnF 'a.b(c)' .` |
| Строки БЕЗ совпадения | `rg -v INFO файл` | `grep -v INFO файл` |
| Включая скрытое и игнорируемое | `rg -uu TODO` | по умолчанию |

⚠️ Ловушка: у `grep` флаг `-r` — «рекурсивно», у `rg` — «заменить в выводе»
(`--replace`). Поэтому команды grep из интернета в rg не переносятся вслепую.

**Упражнения:**
1. `rg TODO` и `grep -rn TODO .` — сравни: grep нашёл лишнее в `target/` и `.git/`.
2. `rg -c ERROR logs/` — сколько ошибок в логе.
3. `rg -C 1 'id=34\b' logs/app.log` — строка с id=34 и соседние.
4. `rg -o 'id=\d+' logs/app.log | head` — `-o` выводит только совпавший кусок.

## 6. Замена текста: sd и sed

| Задача | sd | sed |
|---|---|---|
| Заменить в файле (на месте) | `sd 'old' 'new' файл` | `sed -i 's/old/new/g' файл` |
| Только показать результат | `sd -p 'old' 'new' файл` | `sed 's/old/new/g' файл` |
| В потоке | `echo hi \| sd hi bye` | `echo hi \| sed 's/hi/bye/'` |

**Упражнение:** `sd -p 'println' 'eprintln' src/main.rs` — посмотри, потом
выполни без `-p` и проверь `git diff`.

## 7. fzf — интерактивный выбор из любого списка

```fish
code (fd -e md | fzf)                                       # выбрать файл и открыть
rg -l TODO | fzf --preview 'bat --color=always {}'          # с предпросмотром
git switch (git branch --format='%(refname:short)' | fzf)   # выбрать ветку
```
Внутри fzf: печатать — фильтр, стрелки или `Ctrl+J`/`Ctrl+K` — перемещение, `Tab` —
отметить несколько (если включено `-m`), `Enter` — выбрать.

## 8. Git

| Команда | Что делает |
|---|---|
| `git status -sb` | короткий статус |
| `git add -p` | добавлять изменения по кусочкам |
| `git commit -m 'текст'` | коммит |
| `git log --oneline --graph -15` | история деревом |
| `git diff` / `git diff --staged` | изменения (через delta, с подсветкой) |
| `git switch -c ветка` | создать ветку и перейти |
| `git restore файл` | отменить несохранённые правки файла |
| `git stash` / `git stash pop` | убрать правки «в карман» и вернуть |
| `lg` | lazygit |

Клавиши lazygit: `Space` — stage/unstage, `c` — коммит, `P` — push, `p` —
pull, `Tab` — между панелями, `?` — все клавиши, `q` — выход.

**Упражнение:** в `project` поменяй строку в `notes/todo.md`, сделай `git diff`,
потом закоммить через `lg`.
